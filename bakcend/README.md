# Belleful Backend v2.0 🚀

Production food ordering API - Clean, secure, scalable.

## Quick Start
```bash
npm install
npm run dev  # http://localhost:3500/health
```

## Features
- ✅ Auth (Email OTP + Google OAuth + Reset)
- ✅ Menu w/ inventory
- ✅ Cart & Orders (full lifecycle)
- ✅ Payment upload (Cloudinary)
- ✅ Admin dashboard (stats/charts)
- ✅ Email notifications
- ✅ Vercel deployment ready
